# 十日客栈

一款以中国古代客栈与武侠对决为主题的竖屏卡牌游戏，包含客栈经营和回合制战斗两种主要玩法。

## 主要功能模块

- **客栈经营**：通过拖放、堆叠卡牌完成采买、烹饪、待客、设施升级和人员安排，并推进十日经营战役。
- **武侠战斗**：选择拳师或剑客，围绕卡牌出招、敌方意图、攻防节奏、战斗距离、架势、势与绝招进行双拍回合对决。
- **成长与存档**：记录经营进度、卡组、人员、设施和战役状态。
- **移动端交互**：采用竖屏布局，支持鼠标与触摸操作，并提供角色动画和战斗特效。

## 技术栈

- TypeScript
- React 19、Next.js 16
- Phaser 3
- Vinext、Vite
- Cloudflare Workers / Sites
- Node.js Test Runner

## 项目结构

- `app/`：页面、客户端入口及游戏逻辑。
- `app/game/`：经营模式、战役模式与战斗模式的核心实现。
- `public/assets/`：场景、人物、卡牌和战斗美术资源。
- `tests/`：玩法规则、交互坐标和页面输出测试。
- `worker/`：Cloudflare Worker 入口。

## 本地开发

需要 Node.js 22.13.0 或更高版本。

```bash
npm install
npm run dev
```

## 编译与启动

```bash
npm run build
npm run start
```

## 测试与检查

```bash
npm test
npm run lint
```

## 开发记录规范

每轮用户任务完成后，必须以 UTF-8 编码在根目录 `CHANGELOG.txt` 末尾追加一条记录，不得覆盖或改写既有记录。时间统一使用项目时区（Asia/Tokyo），字段顺序、名称和分隔符固定如下：

```text
[YYYY-MM-DD HH:mm:ss +09:00]
任务：<本轮任务标题>
要求：
- <用户要求 1>
- <用户要求 2>
完成情况：
- <实际完成项 1>
- <实际完成项 2>
验证：
- <检查方式与结果；无验证时写“未执行”>
状态：已完成 | 部分完成 | 受阻
涉及文件：
- <相对项目根目录的路径>
---
```

“部分完成”或“受阻”时，必须在“完成情况”中说明未完成内容和原因；一轮任务只写一个记录块。

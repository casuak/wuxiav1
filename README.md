# 叠叠客栈 · 竖屏十日经营

一个以中国古代客栈经营为主题的十日卡牌战役。游戏中的人物、食材、设施、地点、事件与金钱都以卡牌呈现，拖动并堆叠卡牌即可完成全部经营操作。

## 十日成长

从第一日独自经营面摊开始，依次经历招募伙计、修建客房、选择永久招牌菜、应对菜价、雨夜修缮、商队团单、岗位专精、灯会宣传与三阶段终局宴席。移动版压缩了重复待客次数，每日集中在一个新决策；批量备菜后连续上菜还会积累“连桌奖金”。

竖屏桌面分为设施、人手、事件与流转四层。卡牌会稳定跟随最初的抓取点，靠近可堆叠目标时目标会亮起；抓取牌堆中的任意一张牌，会连带它上方的全部卡牌一起移动。任务进度只占用参与任务的卡牌，灶台做菜时仍可用空闲人手采买、整理其他牌堆。不同牌堆之间不会停留在重叠状态：放下牌堆后，被占位的普通牌堆会弹到最近空位，进行中的牌堆保持稳定。

## 第一日流程

1. 将“小掌柜”和“钱串”叠到“清晨菜市”上，花 3 文采买青菜和面粉。
2. 将“小掌柜”“青菜”“面粉”叠到“简陋灶台”上，做出热汤面。
3. 将热汤面叠到客人身上，获得 8 文钱和 1 点口碑。
4. 重复一次采买、下厨、待客流程。
5. 将“小掌柜”和至少 12 文的钱串叠到“露天面摊”上，升级为“一间小客栈”。
6. 查看第一日收账卡与第二日“招人手”预告。

错误组合不会扣除资源，可以直接抓走最上层卡牌重新堆叠。按 `R` 或点击“重开本日”可重新开始。

牌堆采用严格的纵向排列：每张下层牌都会完整露出标题栏，最后拖入牌堆的卡牌始终显示在最上层。牌堆靠近桌面底边时会整体上移，保证每层标题和最上层整张卡牌都留在操作区域内。

卡牌底部说明会按中文字符自动换行，并为右下角徽章保留固定安全区。每次铜钱入账都会在“钱串”上播放醒目的“+N 文”浮字、徽章弹跳与绿色闪光，同时立即刷新余额。

## 技术与内容

- TypeScript、React、Phaser 3、Vinext
- 430 × 860 原生竖屏逻辑画布，按设备像素密度生成高分辨率缓冲
- 系统中文黑体与 2× 文字纹理，避免小字号画布文字发虚
- 鼠标与触摸拖拽
- 六组原创 AI 生成手绘图集：人物、食材/菜肴、场景/设施与十日事件素材
- 本地保存完整十日进度，不依赖后端服务

## 交互碰撞调试

卡牌容器统一使用 Phaser 原点归一化后的 `0..width / 0..height` 本地命中区域；拖放则按照卡牌的世界坐标矩形重叠面积判定，避免缩放后产生偏移。访问地址后追加 `?debugHitboxes=1` 可以显示卡牌、遮罩和按钮的实际命中轮廓。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

核心玩法位于 `app/game/campaignInnGame.ts`，页面入口位于 `app/page.tsx`。
